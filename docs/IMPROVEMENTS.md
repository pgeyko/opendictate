## 1. Выбор модели (все поддерживаются)

\*Для фразы 5 с на десктопном CPU. Источник всех файлов:
`https://huggingface.co/ggerganov/whisper.cpp/resolve/main/<file>`.
НЕ включаем: `*.en` и `distil-*` (только английский).

### 1.2 Механика
- Хранилище: `~/.local/share/opendictate/models/<file>`, докачка по выбору.
- `SttEngine` уже принимает путь — добавить резолвер `preset -> path` + автозагрузку.
- CLI: `--model small` (имя пресета) или `--model /путь/к.bin` (как сейчас).
- Трей: подменю «Модель» с radio-пунктами и пометкой текущей; смена = перезагрузка движка на лету (drop + new, ~1 с).
- GUI: dropdown с описанием веса/скорости + прогресс скачивания.
- Конфиг: поле `model = "base"` в `~/.config/opendictate/config.toml`.

## 2. Качество распознавания (независимо от модели)

1. **Initial prompt** (дешево, 0 мс): дефолтный bilingual IT-пrompt
   `"Это разговор о программировании на русском с английскими терминами. Термины: whisper, лог, буфер обмена, PipeWire, демон, токен, коммит."`
   + редактируемый в конфиге/GUI. Флаг whisper-cli `--prompt`.
2. **Язык**: `ru` по умолчанию, опция `auto` (CLI `--language auto`, трей, GUI).
   При `auto` английские термины остаются латиницей.
3. **Декодер**: beam 5 (`-bs 5`), temperature fallback (`-tp 0,0.2,0.4`),
   убрать `single_segment` (полная сегментация точнее на длинных фразах).
4. **VAD-обрезка тишины**: energy-RMS порог по краям записи (без новых зависимостей),
   иначе галлюцинации на тишине.
5. **Нормализация пика** к ~0.9 перед отправкой в модель (тихий OpenMic — в норму).
6. **No-speech threshold** (`-nth 0.6`): пустые фрагменты отбрасываются, а не глючат.

## 3. Буфер + авто-Ctrl+V через uinput (полный разбор)

### Почему именно так
- Печатать посимвольно через uinput — боль с кириллицей (зависит от раскладки).
- Вставка «из буфера по Ctrl+V» layout-независима: раскладку обрабатывает сам тулкит
  активного приложения. Wayland/X11/терминал — везде работает одинаково.

### Схема
1. После распознавания: `wl-copy` (как сейчас) — всегда.
2. Если `auto_paste = true` (дефолт): эмулировать **только нажатие Ctrl+V**
   через виртуальную клавиатуру `/dev/uinput`:
   `LEFTCTRL down → V down → V up → LEFTCTRL up`, паузы ~10 мс.
3. Права: `/dev/uinput` обычно `root:input` — пользователь уже в группе `input`
   (нужна для evdev-хоткея), иначе graceful fallback: только буфер + hint в лог.
   Дополнительно шиппим udev-правило `assets/90-opendictate.rules` в install.sh.
4. Реализация: новый модуль `opendictate-input::AutoPaster` на крейту `evdev`
   (`UinputDevice`), открывается лениво один раз при старте, `Send`-хендл
   в главный цикл. Ошибки открытия — не фатальны.
5. Настройки: `auto_paste = true` в config.toml; CLI `--no-auto-paste` /
   `--auto-paste`; пункт в трее; тумблер в GUI. После вставки — короткий лог.

### Граничные случаи
- Поле ввода потеряло фокус за время распознавания → вставится не туда же,
  куда вставился бы ручной Ctrl+V. Лечится опцией задержки (0 мс по умолчанию,
  настраивается) — не усложняем v1.
- Приложения, перехватывающие Ctrl+V (vim, tmux) — пользователь выключает
  автовставку и жмёт сам. Это штатно.

## 4. GUI на GTK4 (по образцу openmic-gtk)

Новый крейт `opendictate-gui` (gtk4 + libadwaita, deps уже стоят):
- **Секция «Модель»**: dropdown пресетов с весом/скоростью, статус
  («загружена», «качается N%»), кнопка «Скачать».
- **Секция «Язык»**: `ru / en / auto` + текстовое поле initial prompt.
- **Секция «Ввод»**: тумблер автовставки, выбор хоткея (Pause/F12/ScrollLock),
  режим Push-to-Talk/Toggle (задел на будущее), кнопка «Проверить» (тестовая фраза).
- **Секция «Статус»**: движок готов/нет, текущая модель, последняя фраза + время.
- Связь с демоном: unix-сокет `$XDG_RUNTIME_DIR/opendictate.sock`
  (`status`, `set {model,lang,auto_paste,prompt}`, `reload`), демон — единый
  процесс (hot-reload движка без рестарта), GUI — супервизор как в openmic
  (поднимает демона, гасит своим выходом; чужой не трогает).

## 5. Конфиг (единый источник правды)

`~/.config/opendictate/config.toml`:
```toml
model = "base"          # пресет или путь
language = "ru"         # ru | en | auto
auto_paste = true
prompt = "..."          # initial prompt, пусто = дефолтный
hotkey = "pause"        # pause | f12 | scrolllock (задел)
```
Приоритет: CLI-флаги > конфиг > дефолты. Трей/GUI пишут конфиг + шлют `reload`.
