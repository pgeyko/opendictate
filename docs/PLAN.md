# OpenDictate — План проекта и техническое задание

Автономная легковесная система голосовой диктовки на Rust для Linux (Wayland / X11 / ALT Linux).

---

## 1. Цели и видение

- **Удобная голосовая печать на русском языке**: зажал клавишу (или нажал хоткей) в любом приложении (браузер, IDE, Telegram, терминал) -> надиктовал фразу -> отпустил -> текст со знаками препинания напечатался в фокусе ввода.
- **Низкое потребление ресурсов**:
  - В режиме ожидания: **0% CPU, < 15 МБ RAM**.
  - Во время распознавания: локальный инференс на CPU через оптимизированный C++ движок (`whisper.cpp` / GGML) без требований к GPU и без облаков.
- **Мультиязычность**: русский язык по умолчанию, архитектурная поддержка английского и других языков без доработок кода.
- **Работа в фоне**: сворачивание в системный трей (StatusNotifierItem), запуск вместе с системой.
- **Универсальность ввода**: эмуляция ввода через Linux `/dev/uinput` (работает в Niri, GNOME, Sway, Hyprland, KDE) + быстрый фолбэк через системный буфер обмена.

## 3. Стек технологий

| Компонент | Технология | Обоснование |
|---|---|---|
| **Язык** | **Rust** (2021 edition) | Быстродействие, безопасность памяти, один самодостаточный бинарник. |
| **STT Движок** | **`whisper.cpp`** (биндинг `whisper-rs`) | Оптимизированный инференс на C++/GGML. Поддержка квантования (Q5/Q8), скорость на CPU в 4-6 раз быстрее реального времени. |
| **Аудиозахват** | **PipeWire / CPAL** | Захват стандартного источника по умолчанию (микрофон OpenMic, гарнитура, веб-камера) с ресемплингом в 16 кГц моно. |
| **Шорткаты** | **`evdev`** / **XDG Portal** | Прямой перехват нажатия клавиш на уровне ядра Linux, обходя ограничения безопасности Wayland. |
| **Эмуляция ввода** | **`/dev/uinput`** (`evdev-rs`) + `wl-copy` | Ввод текста на уровне виртуального устройства клавиатуры ядра (работает во всех окнах, включая терминалы). |
| **Трей и Настройки** | **`ksni`** (StatusNotifierItem) + **GTK4/Libadwaita** | Нативная иконка в трее с меню: выбор языка, модели, смена горячей клавиши. |

## 4. Модели распознавания

Программа автоматически кэширует модели в каталоге `models/` (или `~/.cache/opendictate/`):

1. **`whisper-tiny` (мультиязычная, ~75 МБ)**:
   - Минимальная нагрузка (<100 МБ ОЗУ), ультрабыстрый инференс на старых ПК.
2. **`whisper-base` (мультиязычная, ~140 МБ) — Рекомендуемая по умолчанию**:
   - Превосходное качество распознавания русской речи со сленгом и пунктуацией.
3. **`whisper-small` (мультиязычная, ~460 МБ)**:
   - Максимальная точность для сложной терминологии и больших объёмов текста.

## 6. Режимы работы клавиши

- **Push-to-Talk (по умолчанию)**:
  - Зажал клавишу (`Pause`, `F12` или шорткат) -> раздаётся тихий звуковой клик, загорается иконка в трее, идёт запись.
  - Отпустил клавишу -> запись останавливается, нейросеть за 200–300 мс распознаёт фразу и печатает её в фокус.
- **Toggle Mode**:
  - Нажал один раз -> запись пошла.
  - Нажал второй раз -> остановка и печать.

- [x] **Этап 1: Ядро STT и эмуляция ввода**
  - Подключение `whisper-rs` и автоматическая загрузка модели `ggml-base.bin`.
  - Эмуляция клавиатуры `/dev/uinput` и вставка русского текста.
- [x] **Этап 2: Захват звука и глобальная клавиша**
  - Захват звука с микрофона через CPAL/PipeWire в кольцевой буфер 16 кГц.
  - Глобальный перехват выбранной клавиши (по умолчанию `Pause/Break`).
- [x] **Этап 3: Интерфейс и системный трей**
  - Интеграция в системный трей (ksni).
  - Звуковые сигналы (бип начала и окончания записи).
  - Скрипт сборки и установки (`install.sh`, `.desktop`).
- [ ] **Этап 4: Тестирование и релиз**
